# Artifact ports

Driver metadata uses concrete tags such as `artifact-out:model/3d`, `artifact-in:image/raster`, or `artifact-out:document/pdf`.

Match a producer output tag to a consumer input tag of the same semantic type. Discover concrete capabilities at runtime; this Skill intentionally does not hardcode every supported media type or application.

A tag is compatibility metadata, not proof that the route is currently available and not a filesystem permission.
