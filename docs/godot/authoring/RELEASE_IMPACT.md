# Godot semantic authoring release impact

Godot authoring is additive to the existing Godot driver. Existing paired-editor capabilities retain their public names. The branch adds managed Composition authoring, native verification, logical managed-project selection for runner/export routes, a production Skill and development evidence/package tooling.

Managed authoring is opt-in through owner configuration. Without authoring config the eight Composition-plan lifecycle routes are absent. `composition.native.verify`, `composition.native.query`, `composition.native.tracks.page` and `composition.native.keys.page` additionally require a pinned runner and are not exposed with only one side configured. Legacy context-free execution cannot manufacture owner-bound plans, targeted native-query authority or native paging authority.

The typed intent plus provider derivation record are the source of truth for managed content. The profile now models typed AnimationTree state machines/BlendSpace1D graphs, explicit shared versus local-to-scene material bindings, bounded arithmetic/comparison/logic/clamp/lerp expressions, position/rotation/scale/reparent behavior actions, and physics-tick vector acceleration with max-speed bounds for declared gravity; none expose arbitrary property/method surfaces. Per-file Project Graph asset/revision identities remain visible through Composition inspect. Generated Godot files remain editable in normal Godot, but a manual change becomes DIVERGED and blocks automatic overwrite/run/export until an explicit decision and replan.

Initial native acceptance target is Linux with pinned Godot 4.7.2. Portable source contracts do not imply Windows/macOS native production support. Exported games are intended to run without Semwright; editor bridge, native observer and private state are not normal package contents.

The branch consumes Composition, Project Graph and Effect Conformance contracts at compatible revisions. Normal pushes now run affected-area iteration lanes only and emit scope evidence; they are not integration certification. Full Godot certification is reserved for one exact candidate SHA and forces model/native/persistence/export/hostile/cross-app plus the gated package/certification manifest. Merge does not close R16. Exact-SHA certification `a3c2180c6406f3664e9e8c4870438cfeb20655dd` / run `36824957800` passed model, native, persistence, export, hostile, final Blender cross-app oracle and package prerequisites after final Project Graph integration. `GODOT_AUTHORING_READY` also remains false while the shared PlanVault lacks the explicit Partial/Unknown reconciliation transition required for safe retry authority.
