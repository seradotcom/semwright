# Community conduct

Semwright welcomes technical disagreement, bug reports and critical review. Treat contributors and
users with respect and keep discussion focused on code, evidence and tradeoffs. Harassment, threats,
discriminatory abuse, unwanted sexual attention and publishing private information are not
acceptable.

Do not pressure anyone to run unreviewed automation against personal accounts, share credentials or
claim verification they did not perform. Reproducible negative findings are welcome. Credit prior
work, preserve licenses and redact unrelated user data from reports.

Repository maintainers may moderate or remove abusive content and may restrict participation when
needed to protect the community. Non-sensitive project questions belong in the public issue tracker;
security vulnerabilities should use the repository's private vulnerability-reporting channel.

This code applies to project-controlled issue trackers, pull requests, review discussions and other
official Semwright community spaces.
