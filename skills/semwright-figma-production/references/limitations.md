# Current limitations and fail-closed cases

Automated repository evidence covers fake-Figma protocol E2E, plugin runtime tests, catalog/schema consistency, and Driver Host sandbox integration. It is not a real-account certification.

A real call can still be unavailable because of:

- Design/FigJam/Slides/Buzz editor type;
- plugin manifest permissions;
- current document/session generation;
- collaborative revision drift;
- Motion Beta availability;
- team/library or plan access;
- unconfigured protected REST credentials.

Do not convert those conditions into alternate arbitrary-JavaScript or coordinate routes. Report the unavailable semantic route and use a documented capability only if it independently satisfies the user's intent.
