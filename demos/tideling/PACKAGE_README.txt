TIDELING — playable reef demo
Run ./Tideling.x86_64 (on Linux, chmod +x Tideling.x86_64 if extraction lost permissions).
Keep Tideling.pck beside the executable. No cloud service or store account is needed.
WASD/arrows or left stick: swim. Space/A: burst. Enter: start. Escape/Start: pause. M: mute.
R retries after the ending. You grow by eating fish marked with small brackets.
Diamonds mark dangerous hunters. The Bluegold candidate is disabled in this baseline.

Original models and synthesized audio, under the Semwright repository licenses.
Fraunces title font: SIL OFL, see FONT-LICENSE.txt.
This portable demo uses the Godot editor-capable binary and an exported game pack.
Baseline art was authored directly; the separate BlueGold variant records the Semwright-created species.
See SOURCE_SHA.txt and SHA256SUMS.txt for this build's identity.
