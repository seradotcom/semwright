# TIDELING visual system
Experience mode. The original modeled fish and reef lead; HUD recedes.
Use the authored palette and silhouette contract in design/ART_DIRECTION.md.
Water #062B40 / #167E90, type #F4ECD9, accent #FFAE70, secondary #A6DCD4.
HUD: 18 px body, 13 px captions, 28 px score. Main title 74 px serif; controls 18 px sans.
Margins 44 px at 1280×800; scale via canvas_items stretch. No card grid or level-up dialog.
Title is an overlay on the actual live reef; Enter or the single Dive in button starts play.
Escape pauses, M mutes, R retries only after ending. Keyboard focus stays visible.
Growth: 0.9 second breath in camera scale and light, no flashing. Dash trails stay short.
