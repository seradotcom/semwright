# Typed authoring boundary

The versioned `AuthoringIntent`/`BlenderAuthoringSpec` contract and the full intent-schema digest pinned in `ProfileIdentity` are authoritative. The public capability catalog intentionally exposes a bounded transport envelope so an external Registry can validate it within its structural budget; the driver then strictly decodes that envelope into the full typed intent and runs `BlenderAuthoringSpec::validate`. A create request is `{ "intent": { "kind": "create", "spec": ... } }`. Fields in `spec` are version, collection, meters_per_unit, textures, materials, entities, relations and animation. Unknown fields are rejected by the strict typed decode even when the shallow transport envelope does not enumerate every nested field. Fixtures under `fixtures/blender-authoring/` are development inputs; the native acceptance suite still sends them through Broker → Driver Host → Composition → Blender.

Lengths use explicit meters_per_unit; rotations are radians. Supported geometry includes box, cylinder, bounded mesh arrays, editable bounded POLY curves with extrusion/bevel geometry, empty, armature, camera and area light. Owned mesh entities may also declare `shade_smooth` plus bounded typed custom attributes: POINT/FACE/CORNER domains with float, float-vector or float-color values whose cardinality must match source topology. Native readback exposes managed attributes, a polygon-normal digest and whether normals came from source RNA or evaluated geometry; this is structural evidence, not a custom-normal artistry claim. The enriched drift fingerprint is explicitly `blender-source-projection-v4`; v4 also records axis-selective COPY_LOCATION constraint state used by the typed `align` relation. `mesh_instance` intentionally shares the source mesh datablock and therefore rejects material/modifier/attribute/shading writes. `mesh_copy` is the explicit isolation primitive: the Blender backend copies the source mesh datablock first, then may assign its own material slots, typed managed attributes and non-destructive modifiers. It does not silently duplicate linked/unmanaged data.

Bevel, mirror, subdivision, array and typed exact-solver Boolean remain non-destructive modifiers. Curves use one bounded native POLY spline with explicit extrusion/bevel geometry. Materials cover bounded base color, roughness, metallic, emission and opacity on the pinned Principled node; arbitrary shader source remains excluded. Texture resources are relative workspace assets with a declared SHA-256 and `sRGB`/`Non-Color` intent. TextureAsset v1 has an external-reference-only storage policy: the driver preserves the granted source path/hash and never packs or copies texture bytes implicitly into another location. A future pack/copy mode would require an explicit typed operation/write-set rather than changing this behavior silently. Bindings are closed to base color, scalar roughness/metallic/opacity channels, emission, and a bounded Normal Map strength; the backend rehashes the file and verifies the native node/link topology. URLs and unmanaged paths are never texture inputs. Skinning uses explicit bounded weights and declared bones. Animation uses bounded linear keyframes in Blender 4.5 slotted Actions, with rates represented through A's media-time Rate. Optional NLA tracks/strips may only arrange the managed Action generated for that same entity; external Actions are rejected. Native readback verifies the NLA arrangement, while GLB export only claims animation presence/fidelity supported by glTF and does not claim preservation of Blender-specific NLA track structure.

Use `composition.inspect.page` for objects, bones, actions, curves, keyframes and selected properties when exhaustive traversal matters. Provider cursors are single-use and bound to authenticated Owner, native session, domain and source fingerprint; replay or any intervening native drift makes the cursor stale.

`composition.measure` reports source or evaluated state explicitly. A sampled animation measurement supplies `{frame, rate}` where `rate` is A's exact `media-time::Rate`; sampled measurement requires evaluated state, the rate must match the managed Blender scene rate, and the driver restores the prior frame/subframe before returning. The result reports exact rational `sample_time`, evaluated visibility and bounded pose-bone matrices for the selected frame only; it never promotes two sampled poses into an all-time animation claim. Pairwise mesh collision evidence has two stages: AABB is only a broad-phase filter; when AABBs overlap and the declared object/triangle budgets allow complete evaluation, the backend performs world-space triangle narrow-phase with segment/triangle tests and a coplanar 2D triangle test. If the method or budget is insufficient it returns UNKNOWN. Pairwise object collision does **not** prove self-intersection, so `mesh_self_intersections` remains UNKNOWN.

The runtime target is Blender 4.5.14 LTS inside the existing Linux Driver Host sandbox. New Composition calls require authenticated protocol-v3 request context and negotiated progress/cancellation support; protocol v2 does not preserve the Broker session inside the driver. Legacy protocol-v1 capabilities remain separate and cannot manufacture an authoring Owner.

Geometry arrays are data; Python source, expression strings, generic RNA method names, callbacks, plugins and downloads are not valid authoring inputs. Fixed first-party Python inside the sealed Blender driver is backend implementation, not caller code.

Ordinary incremental edits are separate from repair: `transform` and `material_slots` require a fresh managed fingerprint, and `material_slots` is denied on shared mesh data unless the caller first chose explicit `mesh_copy` isolation. The only repair surface is transform-only, parent-PlanVault-bound repair. It cannot regenerate a created asset, remesh, remove parts, change materials/rigs, bake, or expand authority.

Still open: node-graph authoring beyond the closed typed PBR network, cross-format NLA track preservation, host-admitted C receipts spanning export/handoff/import, and an exact-SHA D Godot cross-app GLB roundtrip. F effect evaluation is wired to trusted native readback, but it does not close those separate obligations; exact-SHA E acceptance is represented by the CI artifact rather than asserted by this prose.
