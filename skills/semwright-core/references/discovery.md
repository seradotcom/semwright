# Discovery

Start with the smallest query that expresses the task. Prefer semantic tags and object types when the application driver publishes them.

A search result is evidence that a capability is registered. Its route list separately reports whether a current provider route is usable. Neither fact is authorization.

Before mutation, describe the exact capability you intend to call. Re-read the schema when a lock or prior conversation suggests descriptor drift. Descriptor, provider provenance, required scopes, risk, idempotency, and route status are runtime facts; do not copy stale versions into the Skill.

For a cross-application task, discover producer and consumer independently. A matching output tag and input tag describe semantic compatibility; they do not create filesystem grants or policy consent.
