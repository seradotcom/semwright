# Audio technical fixtures

`av-technical-fixture.json` is synthetic engineering data, not launch-film content.

It provides a neutral silent stem, exact markers/ranges, a tempo/meter change, bounded MIDI note/control metadata, shared media-time cues (including synthetic narration word timing), an explicit overlap/fade crossfade, 44.1 kHz to 48 kHz duration preservation, and an NTSC 30000/1001 sync point.

No fixture claims musical quality, speech recognition, real narration, hardware latency, or a promotional soundtrack. Digests are synthetic identities used only to verify stale/dependency handling.
