# Release impact — G lab

This branch adds development-only tests, fixtures, evidence validation, reports and a dedicated diagnostic workflow. It does not alter Semwright product crates, native drivers, shared manifests/locks, capability catalogs, permissions, runtime binaries, licenses, releases or main. No new production dependency is introduced by the Python standard-library harness.

No new operating-system or native-application support is claimed. The experimental enclosure is Linux/GitHub-hosted only. Windows and macOS isolation, native persistence acceptance and the combined creation wave remain unverified by G.

The source package is a reproducible backup of G's changes, not an installable product build. Package integrity checks establish the bytes of that backup, not product safety or readiness. A draft PR, a green selector, a successful fixture, or a green author branch is not an independent security certification. R16 remains open.
