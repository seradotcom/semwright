# Responsive design

Figma is not a runtime CSS engine. Treat responsive intent as explicit editable design profiles such as desktop, tablet and mobile frames.

A profile can change semantic composition: split versus stack, ordering, width, CTA behavior, spacing or media placement. Compile each profile into native Figma structures rather than claiming browser-like runtime responsiveness.

Validate each profile's declared constraints against observed state. A mobile adaptation should be a real native layout variant, not merely a scaled desktop screenshot.
