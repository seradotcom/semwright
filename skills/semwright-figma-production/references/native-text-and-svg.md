# Native text and SVG

Headings, body copy, navigation, buttons, labels, captions, form labels, annotations and other ordinary UI strings should be native Figma TextNodes whenever the official API supports them.

SVG/vector import is appropriate for logos, icons, illustrations, decorative geometry and vector artwork. It is not a shortcut for composing an entire page or for hiding ordinary UI text inside outlines.

A suspicious text-bearing vector finding is evidence for review, not blanket proof that every vector containing glyph-like geometry is wrong. Legitimate logos and artwork can remain vectors.
