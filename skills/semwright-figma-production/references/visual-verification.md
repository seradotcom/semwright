# Visual verification

Use artifact-backed verification after semantic measurement and validation, not instead of them.

A verification render is useful evidence for model/human judgment about hierarchy, balance, brand fit and other aesthetic concerns. Object identity, refs, layout relationships, bindings and deterministic defects come from semantic state.

If visual artifact generation fails, do not claim visual verification. Preserve artifact token/type/digest metadata and release provider-owned handles when the workflow is complete.
