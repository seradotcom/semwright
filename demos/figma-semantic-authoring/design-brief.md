# Design brief — Semwright launch landing

Create a polished launch landing for Semwright as a native editable Figma Design document.

## Message

Semwright is the semantic execution layer between capable agents and real software. The model should decide intent and creative tradeoffs; Semwright should own typed operations, policy, object identity, measurement, evidence and deterministic verification.

Core line: **Software agents should act on meaning, not pixels.**

## Visual direction

- warm ivory / paper field;
- deep ink with restrained cobalt;
- editorial hierarchy and generous whitespace;
- real product/evidence language rather than fake testimonials;
- strong typography with simple geometric evidence panels;
- restrained, technical, confident composition.

Avoid purple/neon AI SaaS, glowing orbs, random gradients, fake testimonials, generic bento spam, terminal-window wallpaper and whole-page SVG composition.

## Required variants

Desktop: 1440 px root.
Mobile: 390 px root.

Mobile is a real separately authored editable variant: stack hero content, text before evidence visual, full-width CTA, compact proof/architecture sections.

## Native requirements

UI copy must remain TextNodes. Use Auto Layout where semantically appropriate. Reuse the required Figma variables/styles/component when present. The CTA must remain an instance. Do not detach instances as a convenience strategy.

The finished document must support follow-up semantic editing and node-specific verification.
