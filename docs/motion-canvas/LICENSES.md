# Licenses and provenance

Motion Canvas core, 2d, UI, Vite plugin and official FFmpeg exporter: MIT.
Vite, TypeScript, pngjs and the Lezer grammars: their npm package license files
and locked package metadata are retained by the dependency installer.
Playwright: Apache-2.0; browser redistribution is not part of this source PR.
Instrument Sans and IBM Plex Mono: SIL Open Font License 1.1, obtained from exact
Fontsource packages, not copied out of the owner's font installation.

No font binaries or node_modules are committed or supplied as source attachments.
The film uses rendered typography. Its build resolves fonts from the lockfile.
Website source was inspected read-only. Its generated landscape is not being
reused as an original illustration; any site capture must be labeled actual
product footage and recorded with source/date/hash in ASSETS.json.

Original procedural film sound will be generated from repository source. There
are no paid media APIs, commercial music tracks, or downloaded stock assets.
The final per-file asset ledger is demos/launch-film/ASSETS.json.
